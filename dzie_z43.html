Dziewulski — Teoria dotyczaca petli

Trzy rodzaje petli w jezyku JavaScript.

1) Petla for

Konstrukcja:

for (zainicjowanie_zmiennej; warunek_konczacy_wykonywanie_petli; zmiana_zmiennej) {
    kod ktory zostanie wykonany pewna ilosc razy
}

Opis: petla for sluzy do powtarzania kodu okreslona (zwykle znana) ilosc razy. Najpierw inicjuje zmienna sterujaca, sprawdza warunek, wykonuje kod, a na koncu zmienia zmienna sterujaca i ponownie sprawdza warunek.

Schemat blokowy:

        [ START ]
            |
   [ inicjalizacja zmiennej ]
            |
        [ warunek? ] ---- NIE ----> [ KONIEC ]
            | TAK
        [ kod petli ]
            |
   [ zmiana zmiennej ]
            |
        (powrot do warunku)

2) Petla while z kontrolowanym wejsciem

Konstrukcja:

while (wyrazenie_sprawdzajace_zakonczenie_petli) {
    ...fragment kodu ktory bedzie powtarzany...
}

Opis: petla while najpierw sprawdza warunek, a potem cos wykonuje. Petla moze sie nie wykonac ani razu, jesli warunek od poczatku jest falszywy (kontrolowane wejscie).

Schemat blokowy:

        [ START ]
            |
        [ warunek? ] ---- NIE ----> [ KONIEC ]
            | TAK
        [ kod petli ]
            |
        (powrot do warunku)

3) Petla do...while z kontrolowanym wyjsciem

Konstrukcja:

do {
    ...fragment kodu ktory bedzie powtarzany...
} while (warunek)

Opis: petla do...while zawsze wykona jedna iteracje, zanim sprawdzi warunek. Zawsze wiec wykona jakies zadanie co najmniej raz (kontrolowane wyjscie).

Schemat blokowy:

        [ START ]
            |
        [ kod petli ]
            |
        [ warunek? ] ---- TAK ----> (powrot do kodu petli)
            | NIE
        [ KONIEC ]
